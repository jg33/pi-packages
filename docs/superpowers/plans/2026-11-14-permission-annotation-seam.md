**Evidence:** docs/superpowers/plans/artifacts/evidence-permission-annotation-seam.md (HEAD 3a5081ab)

**Goal:** Land increment A of ADR 0011 §8 in `packages/pi-permission-system`: a named, opt-in, config-ordered, fail-safe, timeout-bounded annotator registry whose output the prompt renders as marked, attributed, advisory text that structurally cannot decide the ask.

**Architecture:** `PromptAnnotation` gains a literal `marking` and a single constructor, so the marker is a property of the slot. A new `AnnotatorRegistry` mirrors `AuthorizerRegistry`; a new `AnnotationRunner` resolves `annotatorChain` in config order (skipping unregistered names, auditing them like `AuthorizerChainAudit`), runs the annotators under one shared deadline, and writes the survivors into the payload. `LocalUserAuthorizer.present` calls the runner on the serving node only, and `renderPromptDialog` lays the annotations out as a separate region after the evidence. An annotator's return type is `string | undefined`, so no verdict can be expressed on that path.

**Tech Stack:** TypeScript (ES2024), vitest (`expectTypeOf` / `@ts-expect-error` checked by `tsc`), Zod config schema, pnpm workspace, Biome + ESLint + rumdl.

## Design decisions

- **D1. Placement.** Annotators run in `LocalUserAuthorizer.present`, before `emitUiPromptEvent`. That is the serving node, where the human is (ADR §8, 0007 §7); a relaying node builds `ParentAuthorizer` instead and never runs one [E30-E32]. The broadcast is built from the original `details`, so it stays annotation-free [E4, E30].
- **D2. Slot model.** `PromptAnnotation` = `{ source, text, marking }`, `marking` a literal `"model-generated"`. `modelGeneratedAnnotation(source, text)` is the only constructor. `source` is the registered name, stamped by the runner. The wire parser re-stamps the marking instead of reading it [E7, E8].
- **D3. Annotator type.** `(input: { payload, signal }) => string | undefined | Promise<string | undefined>`. No verdict is expressible.
- **D4. Deadline.** One shared deadline for the whole chain; annotators run concurrently; those not done by the deadline are dropped and their late answers discarded; each receives an `AbortSignal` that fires at the deadline. Config `annotatorTimeoutMs`, default 1500 ms (A1).
- **D5. Rendering.** Own `layout` call after the evidence; label `model-generated (<source>)`; never painted as a flagged element; first thing to give way under the row budget; capped by `fieldMaxWidth` like any fact [E33-E36].
- **D6. Wire boundary (read side).** Enforcement sits where the *serving* node reconstructs a payload from wire data — `buildForwardedAskPayload`, the sole read path (`forwarded-request-server.ts:115`) — which forces `annotations: []` regardless of what arrived. The trust boundary is the reader: a hostile or buggy child can fill the slot and choose any `source`, so blanking it in the child's writer is cooperative defence, not a control. Child-side blanking, if any, stays as belt and braces. Without the read-side reset a child's annotation would render on the serving node under the model-generated marking, attributed to a source the child chose [E39].
- **D7. Untrusted text.** The runner strips control and format characters (ESC, BEL, bidi overrides) from annotation text, because the dialog's line fitter is ANSI-aware and passes escape sequences through [E38]. It strips whole sequences — CSI, OSC, 8-bit C1 CSI, and the legacy `ESC` + intermediates + final-byte forms (two or three bytes, e.g. `ESC ( B`) — because a one-character fallback would truncate those and leave the rest as printable text (`ESC ( Btext` → `Btext`), which reads as sanitized. What remains must be printable text or a space (a whitelist), line breaks collapse to one space, and the result is one line. The primitives live once, in `src/presentation/printable-text.ts`, shared by the runner's advisory body and the renderer's label.

  Known limits, stated rather than hidden: **no control byte or `ESC` ever survives** (the whitelist drops any leftover), but the *bodies* of unterminated OSC, DCS (`ESC P`), APC/PM (`ESC _`, `ESC ^`) and 8-bit C1 OSC/PM/APC do survive as printable text — cosmetic, since an advisory carries no verdict. And `ESC` + intermediates + final byte can over-consume up to four characters after a lone `ESC` (`a<ESC>   text` → `aext`), accepted because a lone `ESC` is malformed input and the advisory cannot change a decision.
- **D8. Failure logging.** A throwing annotator is logged by error *name* only. A model call's message can echo the request, and the review log is bounded on purpose (ADR 0011 §6).
- **D9. Public API.** `registerAnnotator(name, annotator): () => void` is a required member of `PermissionsService`, with no reader (same rationale as `registerAuthorizer` [E18]). No `ObservedAuthorizerRegistrar` analogue (see Q3).
- **D10. Config keys.** `annotatorChain: string[]` and `annotatorTimeoutMs: number`, mirroring `authorizerChain` / `promptTimeoutMs` [E23-E25].

## Open questions (need a caller decision; the plan proceeds on the stated default)

- **Q1. Latency semantics.** The user chose the ADR-default silent variant: no placeholder. Task 7 implements it as a *bounded pre-render await*: nothing is awaited unless an annotator is both configured and registered (the default), so the default path renders exactly as today; an opted-in operator pays at most `annotatorTimeoutMs` before the prompt appears. The alternative is to render at once and patch a late annotation in. That needs a re-render hook in the inline dialog component, cannot work on the `ui.select` fallback (renders once [E37]), and would touch `permission-prompt-component.ts`, which sits next to another session's in-flight work [E40]. **Recommendation: ship the bounded await; treat live fill-in as a follow-up increment.** If you read "renders immediately" as "never delayed even when an annotator is configured", stop here and decide.
- **Q2. Default deadline.** 1500 ms is an unvalidated guess (A1). It is a config default, so changing it is a one-line edit.
- **Q3. Relaying nodes.** A registration made on a node whose asks are relayed is accepted and never consulted, with no `authorizer_link_vacant`-style record [E21]. ADR 0012 decision 4 would call for one. Left out as beyond "what this increment needs". Recommend a follow-up.
- **Q4. Semver on `PermissionsService`.** A required new method breaks third-party fakes of the interface at their next bump. The model-judge's `makeService` fake is the only one in this repo, and it resolves the published 40.3.0, so it breaks only when that pin is bumped [E22]. Optional would avoid it but breaks the mirror of `registerAuthorizer`. **Recommendation: required.** Also `PromptAnnotation` is a public type and gains a required field [E51]; a consumer constructing a non-empty annotation literal would break.
- **Q5. Evidence text is not sanitized for control characters.** Pre-existing and outside this increment [E38]. Worth its own issue.

 *
 * The slot owns the attribution and the marking, so both are properties of the

export interface PromptAnnotation {

  readonly marking: typeof MODEL_GENERATED;
}

  source: string,
  text: string,
): PromptAnnotation {
  return { source, text, marking: MODEL_GENERATED };
}

 * `PermissionsService.registerAnnotator`; this registry stores it so the
 * `AnnotationRunner` can bind the operator's `annotatorChain` names to it. One
 * annotator per name; a duplicate registration throws.
 *
 * Registration alone shows nothing: an annotator runs only once the operator
 * names it in `annotatorChain` (the opt-in activation model, as for
 * `authorizerChain`). This registry is storage only.
 */

import type { PromptPayload } from "./prompt-payload";

/** What an annotator is shown. */
export interface AnnotatorInput {
  /** The complete payload the gate built (ADR 0011 §2); its annotations slot is empty. */
  readonly payload: PromptPayload;
  /** Aborted when the annotation deadline passes; an answer after that is discarded either way. */
  readonly signal: AbortSignal;
}

/**
 * An annotator: advisory text for the human deciding an ask, or `undefined` to
 * decline.
 *
 * The return type is the structural wall of ADR 0011 §8. It has no way to spell
 * allow, deny, defer, or "do not show this prompt": the chain's verdict type is
 * not reachable from it, so an annotator cannot influence the decision however
 * it is written. Attribution and the model-generated marking are stamped by
 * `AnnotationRunner` from the registered name, never supplied here.
 */
export type Annotator = (
  input: AnnotatorInput,
) => string | undefined | Promise<string | undefined>;

/** Read-only lookup used by the runner (ISP, mirroring `AuthorizerLookup`). */
export interface AnnotatorLookup {
  get(name: string): Annotator | undefined;
}

/** The write surface (ISP, mirroring `AuthorizerRegistrar`). */
export interface AnnotatorRegistrar {
  register(name: string, annotator: Annotator): () => void;
}

/**
 * Persistent registry mapping annotator names to their callbacks.
 *
 * Owned by the extension factory (`index.ts`) so one instance backs both the
 * `registerAnnotator` service surface and the runner's chain resolution.
 */
export class AnnotatorRegistry implements AnnotatorLookup, AnnotatorRegistrar {
  private readonly annotators = new Map<string, Annotator>();

  /**
   * Register `annotator` under `name`.
   *
   * Throws if a name is already taken, which keeps resolution deterministic.
   * Returns a disposer that is identity-guarded, so a stale call cannot evict a
   * later registration.
   */
  register(name: string, annotator: Annotator): () => void {
    if (this.annotators.has(name)) {
      throw new Error(`An annotator is already registered for '${name}'.`);
    }
    this.annotators.set(name, annotator);
    return () => {
      if (this.annotators.get(name) === annotator) {
        this.annotators.delete(name);
      }
    };
  }

  get(name: string): Annotator | undefined {
    return this.annotators.get(name);
  }
}

/**
 * annotation-runner.ts — Resolve the operator's `annotatorChain` and write the
 * answers into a prompt payload's annotations slot (ADR 0011 §8).
 *
 * The runner is the only writer of that slot, and the only thing that stamps an
 * annotation: `source` is the registered name and the marking is the slot's
 * own, so neither is a discipline an annotator author must remember. Its output
 * is a payload, never a verdict — nothing here imports or produces one.
 */

import type { Annotator, AnnotatorLookup } from "./annotator-registry";
import { sanitizeAnnotationText } from "./printable-text";
import {
  modelGeneratedAnnotation,
  type PromptAnnotation,
  type PromptPayload,
} from "./prompt-payload";

/**
 * How long the chain may take when `annotatorTimeoutMs` is not configured.
 * Declared in `config-schema.ts` (the config layer owns config defaults) and
 * re-exported here, because `node --experimental-strip-types` runs the schema
 * generator and cannot resolve this package's `#src` alias.
 */

/** The narrow log seam the runner needs (ISP): a durable record and an operator warning. */
export interface AnnotationAuditLog {
  review(event: string, details?: Record<string, unknown>): void;
  warn(message: string): void;
}

/** The seam `LocalUserAuthorizer` drives: the payload with this node's annotations in its slot. */
export interface PayloadAnnotator {
  /**
   * The payload to show. Returns `payload` itself when nothing was added, so
   * an unchanged prompt is the same object, not merely an equal one.
   */
  annotate(payload: PromptPayload, requestId: string): Promise<PromptPayload>;
}

export interface AnnotationRunnerDeps {
  registry: AnnotatorLookup;
  /** The operator's configured names, read live per ask. */
  getChain: () => readonly string[];
  /** The deadline for the whole chain, read live per ask. */
  getTimeoutMs: () => number;
  log: AnnotationAuditLog;
}

interface NamedAnnotator {
  readonly name: string;
  readonly annotate: Annotator;
}

/**
 * The agent-facing text for a configured annotator that is not registered here.
 *
 * Names the likeliest cause and admits the other, as `unregisteredLinkMessage`
 * does: registration is honored any time before a prompt, so it may yet arrive.
 */
export function unregisteredAnnotatorMessage(name: string): string {
  return (
    `pi-permission-system: annotatorChain names "${name}", but no annotator ` +
    "with that name is registered in this session, so this prompt is shown " +
    "without it. Most often the extension providing the annotator is not " +
    "loaded here; it may also have failed to load. Every skipped prompt is " +
    "recorded in the permission review log as " +
    "annotator_chain_unregistered_link."
  );
}

export class AnnotationRunner implements PayloadAnnotator {
  private readonly warned = new Set<string>();

  constructor(private readonly deps: AnnotationRunnerDeps) {}

  async annotate(
    payload: PromptPayload,
    requestId: string,
  ): Promise<PromptPayload> {
    const annotators = this.resolve(requestId);
    const answers = await Promise.all(
      annotators.map(({ name, annotate }) =>
        this.consult(name, annotate, payload),
      ),
    );
    const annotations = answers.filter(
      (answer): answer is PromptAnnotation => answer !== undefined,
    );
    return annotations.length === 0 ? payload : { ...payload, annotations };
  }

  /**
   * The configured names that resolve, in config order. An unregistered name is
   * skipped fail-safe (more prompting, never less) and audited.
   */
  private resolve(requestId: string): NamedAnnotator[] {
    const resolved: NamedAnnotator[] = [];
    for (const name of this.deps.getChain()) {
      const annotate = this.deps.registry.get(name);
      if (annotate === undefined) {
        this.auditUnregistered(name, requestId);
        continue;
      }
      resolved.push({ name, annotate });
    }
    return resolved;
  }

  private async consult(
    name: string,
    annotate: Annotator,
    payload: PromptPayload,
  ): Promise<PromptAnnotation | undefined> {
    return toAnnotation(
      name,
      await annotate({ payload, signal: new AbortController().signal }),
    );
  }

  /**
   * Record the skip for every ask (the auditor's durable record) and warn the
   * operator once per name (the person about to answer a prompt the annotator
   * should have annotated). Same two rates, and same reason, as
   * `AuthorizerChainAudit`.
   */
  private auditUnregistered(name: string, requestId: string): void {
    this.deps.log.review("annotator_chain_unregistered_link", {
      requestId,
      name,
    });
    if (this.warned.has(name)) {
      return;
    }
    this.warned.add(name);
    this.deps.log.warn(unregisteredAnnotatorMessage(name));
  }
}

/**
 * An answer as an annotation, or `undefined` when it says nothing.
 *
 * The `typeof` check is a runtime guard for an untyped caller: the type says
 * `string | undefined`, but a JavaScript annotator can return anything, and
 * only text becomes an annotation.
 */
function toAnnotation(
  name: string,
  text: unknown,
): PromptAnnotation | undefined {
  if (typeof text !== "string") {
    return undefined;
  }
  const clean = sanitizeAnnotationText(text);
  return clean === "" ? undefined : modelGeneratedAnnotation(name, clean);
}

```ts
  async annotate(
    payload: PromptPayload,
    requestId: string,
  ): Promise<PromptPayload> {
    const annotators = this.resolve(requestId);
    if (annotators.length === 0) {
      return payload;
    }
    // One deadline for the whole chain: annotators run together, so the prompt
    // is delayed by at most the timeout however long the chain is.
    const controller = new AbortController();
    const deadline = new Promise<typeof TIMED_OUT>((resolve) => {
      controller.signal.addEventListener("abort", () => resolve(TIMED_OUT), {
        once: true,
      });
    });
    const timer = setTimeout(() => controller.abort(), this.deps.getTimeoutMs());
    try {
      const answers = await Promise.all(
        annotators.map(async ({ name, annotate }) => {
          const answer = await Promise.race([
            this.consult(name, annotate, payload, controller.signal, requestId),
            deadline,
          ]);
          if (answer === TIMED_OUT) {
            this.deps.log.review("annotator_timed_out", { requestId, name });
            return undefined;
          }
          return answer;
        }),
      );
      const annotations = answers.filter(
        (answer): answer is PromptAnnotation => answer !== undefined,
      );
      return annotations.length === 0 ? payload : { ...payload, annotations };
    } finally {
      clearTimeout(timer);
    }
  }

   * One annotator's answer. Never rejects: a throw is the same as a decline,
   * because an annotator that fails must not be able to stop the prompt (ADR
   * 0011 §8, "unchanged-prompt fallback"). A late result after the deadline is
   * ignored by the race, and a late rejection still lands here, so none is

    name: string,
    annotate: Annotator,
    payload: PromptPayload,
    signal: AbortSignal,
    requestId: string,

        requestId,
        name,
        // The name only: a model call's message can echo the request, and the

        ui: this.deps.ui,
        ...this.deps.getPromptPreferences(),
        notice: describePromptNotice(
          title,
          details.payload.request,
          this.deps.describeSession(),
        ),
      },

      payload,

```markdown
### Prompt annotations

A downstream extension can register a **prompt annotator**: a function that sees the ask and returns a short piece of advisory text, such as a plain-language explanation of a command.
The permission prompt shows that text under a `model-generated (<name>)` label, below the evidence, so it is never mistaken for a fact about the request.

`annotatorChain` is the ordered list of annotator names to consult:

```jsonc
{
  "annotatorChain": ["explainer"],
  "annotatorTimeoutMs": 1500
}
```

Four invariants govern it:

1. **Advisory only.**
   An annotation can never allow, deny, defer, or suppress the ask.
   It is a different kind of value from a chain link's verdict, and the types do not let one stand in for the other.
2. **A missing annotator is skipped fail-safe, and you are told.**
   A name with no registered annotator is skipped and the prompt is shown unchanged.
   The skip is recorded in the review log as `annotator_chain_unregistered_link` for every prompt, and raises one warning per name.
3. **Registration alone shows nothing.**
   Installing an annotator extension gives it nothing; it runs only when you name it here, in this order.
4. **Slow or broken annotators cost nothing but time.**
   An annotator that declines, throws, or has not answered within `annotatorTimeoutMs` adds nothing, and the prompt is shown as it would be without it.
   The deadline covers the whole chain, so an opted-in prompt is delayed by at most that long; with no annotator configured and registered, nothing waits.

An annotation is shown only in the prompt on the session that shows it.
It is never sent to the agent, written to the review log, or broadcast on `permissions:ui_prompt`.
A subagent's forwarded ask is annotated by the session that serves it; annotations a child sends are discarded.
